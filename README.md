Title: MULTI_CLOUD FILE STORAGE APPLICATION

  The Cloud Storage API project is designed to provide a robust and scalable solution for managing file storage, retrieval, and organization in the cloud. The primary objective is to offer seamless and secure access to cloud-based storage with efficient data management operations, including file uploading, downloading, and deletion. This project aims to enhance accessibility, reduce data redundancy, and optimize storage efficiency.
  The significance of this project lies in its ability to simplify cloud storage interactions through a well-defined API, making it easier for users and applications to handle large volumes of data. By leveraging Spring Boot, it ensures high performance, scalability, and maintainability, making it suitable for real-world enterprise applications.
  
Project Scope:
---------------
User Authentication: 
    Secure login and access control to ensure only authorized 	users can manage cloud storage operations.
File Management:
    Upload, download, and delete files.
    Create and manage folders.
API Endpoints:
    RESTful APIs for seamless interaction with the cloud storage system.
Database Integration:
    Store metadata about files and folders using MySQL.

Use Cases:
-------------
File Upload: 
    Users can upload files and track storage usage.
File Download: 
    Users can download stored files.
Folder Management:
    Users can create and organize folders.
Storage Monitoring: 
    Users can view storage usage details.

Technical Stack:
----------------
Programming Languages: Java
Frameworks/Libraries: Spring Boot, Spring Data JPA, Spring Security
Databases: MySQL
Tools/Platforms: Postman, Swagger, Docker, Eclipse/IntelliJ, Git/GitHub

Architecture/Design: 
---------------------
- User logs in and authorizes access to Google Drive & OneDrive 
- Backend (Java) handles API calls for file management 
- Frontend (Angular/JSP) provides an intuitive UI for users 
- Secure OAuth2 authentication for user data protection.
